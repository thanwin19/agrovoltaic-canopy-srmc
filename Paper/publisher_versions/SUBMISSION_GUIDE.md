## Before you submit (the files are drafts)

1. **Use the journal's own template.** These files follow each publisher's general manuscript instructions, not the official journal template. Download the template of the exact journal or conference you choose, and paste the text and figures in. I can rebuild the file for you if you name the journal.
2. **Fill the placeholders** (they are in square brackets): corresponding author and e-mail, ORCID of each author, author contributions, funding, competing interests. I did not invent any of these.
3. **Authors:** the author list is the four students and Dr. M. Meenakshi Devi. Confirm the order and whether your guide is a co-author.
4. **References:** numbered here. Taylor and Francis and some Elsevier journals need author-year (Harvard or APA); change the style to the journal's.
5. **Reference check:** open each reference and confirm it exists and the details are right before submission.
6. **Similarity check:** the college may require a plagiarism report.
7. **Honesty statements to keep:** all results are simulation; the sensors are software models of named devices; the month run uses real weather but simulated sensors; the prototype photo is shown for context and no results come from it.

## Which one to try first

- **IEEE conference** (simulation papers are common there) is the best match for a final-year project at this stage.
- **MDPI** journals (for example Energies, Agronomy, Sustainability) accept simulation studies but check the fees and review process first.
- **Elsevier Solar Energy** and **Springer Nature** journals usually expect field or measured data; the paper is likely to be asked for it. The crop-light protocol in `Proof/11_Simulated_Month_Oct2023/` is the way to get it.
